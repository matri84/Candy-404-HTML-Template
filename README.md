# 🍭 Candy 404 — قالب صفحه خطای آب‌نباتی

**یک صفحه ۴۰۴ مینیمال، مدرن و پرانرژی با حس آب‌نباتی**


> وقتی کاربر راهش را گم می‌کند، تجربه‌ای شیرین و به‌یادماندنی برایش بسازید.

---

## ✨ ویژگی‌ها

- **طراحی آب‌نباتی واقعی** با شکل‌های نرم و گرادینت‌های زنده
- پالت رنگی اختصاصی: بنفش × قرمز × زرد
- انیمیشن‌های روان CSS + تعاملات JavaScript
- دکمه بازگشت به خانه با آیکون خالص SVG
- کاملاً راست‌چین و بهینه‌شده برای زبان فارسی
- فونت وزیرمتن
- ریسپانسیو و سبک
- بدون وابستگی سنگین (فقط فونت خارجی)
